Para seguir el curso necesitas Figma con un plan que permita modos de variables. Para el itinerario de código, además, un entorno de desarrollo web. Revisa esta página antes de empezar para no encontrarte un bloqueo a mitad del curso.

**En esta página**

- [Figma](#figma)
- [Itinerario de código](#itinerario-de-código)
- [Conocimientos previos](#conocimientos-previos)

## Figma

| Qué necesitas | Por qué | Fuente |
|---|---|---|
| Plan **Education, Professional, Organization o Enterprise** | Los modos de variables (por ejemplo, claro y oscuro) solo están disponibles en estos planes. El número de modos por colección depende del plan. | [Figma: Modes for variables](https://help.figma.com/hc/en-us/articles/15343816063383-Modes-for-variables) |
| Permiso de edición en el archivo | Para crear variables, colecciones y modos | No aplica |

<Callout variant="warning">

Con el plan gratuito (Starter) no podrás crear modos. Podrás seguir los módulos 1 a 4, pero no el módulo 5, Modos y temas, que es donde se crea el modo oscuro.

</Callout>

<Callout variant="note">

Leer variables mediante la API REST de Figma requiere plan Enterprise, según el README del [Simple Design System de Figma](https://github.com/figma/sds). En el curso no la usamos: exportamos las variables desde la interfaz de Figma en formato DTCG.

</Callout>

## Itinerario de código

Solo si quieres seguir los bloques **En código**:

- Un editor de código, por ejemplo VS Code.
- Node.js instalado. La versión mínima la marca cada herramienta; consúltala en su documentación de instalación.
- Conocimientos básicos de terminal para instalar paquetes.

El proyecto del curso usa Next.js (App Router), TypeScript y Tailwind CSS v4. No necesitas conocerlos para entender los tokens, pero sí para reproducir el proyecto completo.

Estas son las versiones con las que construimos y probamos esta web en octubre de 2026:

| Herramienta | Versión |
|---|---|
| Next.js | 16.3 |
| Tailwind CSS | 4.3 |
| Terrazzo (`@terrazzo/cli` y `@terrazzo/plugin-css`) | 2.7.1 |
| Node.js | 24 |

<Callout variant="note">

Con versiones posteriores el curso debería seguir funcionando, pero no lo hemos comprobado. Si algo no coincide, revisa la documentación de la herramienta.

</Callout>

## Conocimientos previos

- **Imprescindible:** manejo básico de Figma (frames, componentes, estilos).
- **Útil:** haber aplicado alguna vez un estilo de color o de texto en Figma.
- **Opcional:** CSS básico, para los bloques En código.
