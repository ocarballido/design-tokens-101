# DesignToken101: Decisiones (detalle)

Texto completo de cada decisión: motivo, fuentes, pruebas, opciones descartadas y cambios posteriores. **No se carga al empezar una sesión** (P22): se lee bajo demanda, cuando una tarea necesita el porqué de una decisión. El resumen de una línea de cada decisión y el protocolo entre sesiones están en `docs/decisiones.md`.

Si el resumen y el detalle no coinciden, manda el detalle y se corrige el resumen. Al tomar una decisión nueva, la sesión escribe su fila aquí, con el texto completo, y su resumen en `decisiones.md`, en el mismo commit.

Estados: **Cerrada** (no se reabre sin motivo) · **Provisional** (se puede cambiar antes de publicar) · **Abierta** (por decidir).
