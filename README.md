# Tokens101

Curso web para aprender a trabajar con tokens de diseño: desde decidir qué valores existen en un sistema hasta verlos funcionando en código, con Figma, el formato DTCG y Tailwind CSS.

La web usa el mismo sistema de tokens que enseña.

## Estado

En construcción. El avance de cada frente está en [`docs/estado.md`](docs/estado.md) y las decisiones, en [`docs/decisiones.md`](docs/decisiones.md).

## Estructura

| Carpeta | Contenido |
|---|---|
| `content/` | Lecciones en MDX, por idioma |
| `docs/` | Especificación del sistema de tokens, anatomía de componentes, decisiones y estado |
| `tools/` | Scripts que generan las escalas de color y comprueban el contraste (Python, sin dependencias) |
