# DesignToken101

Curso web para aprender a trabajar con tokens de diseño: desde decidir qué valores existen en un sistema hasta verlos funcionando en código, con Figma, el formato DTCG y Tailwind CSS.

La web usa el mismo sistema de tokens que enseña.

## Estado

En construcción. El avance de cada frente está en [`proyecto/estado.md`](proyecto/estado.md) y las decisiones, en [`proyecto/decisiones.md`](proyecto/decisiones.md).

## Estructura

| Carpeta | Contenido |
|---|---|
| `content/` | Lecciones en MDX, por idioma |
| `proyecto/` | Documentos del proyecto: especificación del sistema de tokens, anatomía de componentes, decisiones y estado |
| `docs/` | Documentación del sistema según la guía de ds4agents |
| `tools/` | Scripts que generan las escalas de color y comprueban el contraste (Python, sin dependencias) y la lógica de las herramientas de la web. La versión ampliada de "Generar escalas" es [colorgods](https://colorgods.com) |
