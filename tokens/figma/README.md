# Variables exportadas de Figma

Archivos DTCG tal como los exporta Figma (vista Variables → clic derecho en la colección → *Export modes*). No se editan a mano: si cambian las variables, se vuelven a exportar y se sustituyen (C10).

Colecciones esperadas (docs/entrega-diseno.md §2): Primitives, Semantic color (Light y Dark), Semantic size y Layout (Desktop y Mobile).
